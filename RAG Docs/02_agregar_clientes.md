# Agregar Clientes + Cotización Automática

## Descripción General

La sección "Agregar Clientes +" te permite registrar nuevos clientes desde la sucursal o expo correspondiente y generar cotizaciones en PDF de forma rápida y profesional.

## Acceso a la Sección

### Desde el Dashboard Principal
1. Inicia sesión en el dashboard
2. Busca la tarjeta "👥 Agregar Clientes +"
3. Haz clic para acceder al formulario de registro

## Funcionalidades Principales

### Agregar Nuevo Cliente

**¿Cuándo usar esta función?**
- Cuando un cliente en la tienda o expo prefiere no registrarse por sí mismo
- Para registrar clientes directamente desde la sucursal correspondiente
- Cuando necesitas crear rápidamente un perfil de cliente para generar una cotización

**Información a Capturar:**
- Nombre completo del cliente
- Correo electrónico
- Teléfono de contacto
- Tipo de cliente
- Sucursal o expo donde se encuentra
- Productos de interés (opcional)

**Pasos para agregar:**
1. Accede a "Agregar Clientes +"
2. Completa el formulario con los datos del cliente
3. Selecciona la sucursal o expo correspondiente
4. Guarda el registro

### Generar Carrito de Compra

Una vez registrado el cliente, puedes crear un carrito de compra con los productos que le interesan.

**¿Cuándo usarlo?**
- El cliente está explorando productos en la sucursal
- Quieres guardar una selección de productos para el cliente
- Necesitas preparar una cotización personalizada

**Pasos para generar carrito:**
1. Selecciona el cliente registrado
2. Agrega productos al carrito desde el catálogo
3. Ajusta cantidades y configuraciones (telas, estructuras, etc.)
4. Guarda el carrito asociado al cliente

### Generar Cotización en PDF

La función más poderosa de esta sección es la generación automática de cotizaciones profesionales en formato PDF.

**¿Cuándo generar una cotización?**
- El cliente solicita precios por escrito
- Necesitas enviar una propuesta formal vía email
- Quieres imprimir una cotización para entregar en persona
- El cliente quiere comparar opciones

**Características de la Cotización PDF:**
- Formato profesional con branding de Kusam
- Lista detallada de productos seleccionados
- Precios individuales y total
- Información del cliente
- Fecha de emisión
- Términos y condiciones (si aplica)

**Pasos para generar cotización:**
1. Verifica que el carrito del cliente esté completo
2. Haz clic en "Generar Cotización" o "Crear PDF"
3. Revisa la vista previa de la cotización
4. Confirma la generación
5. El sistema creará un PDF descargable

**Opciones con el PDF:**
- **Descargar:** Guarda el PDF en tu dispositivo
- **Imprimir:** Envía directamente a la impresora
- **Compartir:** Obtén un enlace o envía vía email

## Mejores Prácticas

### Al Registrar Clientes

**✅ Hacer:**
- Verifica que el correo electrónico esté escrito correctamente
- Confirma el número de teléfono con el cliente
- Selecciona la sucursal o expo correcta donde se encuentra
- Agrega notas si el cliente tiene preferencias específicas

**❌ Evitar:**
- Registrar clientes duplicados (busca primero si ya existe)
- Dejar campos importantes vacíos
- Usar información incorrecta o de ejemplo

### Al Generar Cotizaciones

**✅ Hacer:**
- Revisa que los productos en el carrito sean los correctos
- Verifica los precios antes de generar el PDF
- Confirma las configuraciones de productos (colores, telas, etc.)
- Guarda una copia de la cotización para tus registros

**❌ Evitar:**
- Generar cotizaciones sin revisar el carrito
- Enviar cotizaciones con información incorrecta
- Olvidar actualizar precios si han cambiado

## Flujo de Trabajo Típico

### Escenario 1: Cliente en Sucursal
```
1. Cliente llega a la sucursal
2. Te pide información sobre varios productos
3. Accedes a "Agregar Clientes +"
4. Registras sus datos básicos
5. Seleccionas los productos que le interesan
6. Generas la cotización en PDF
7. Se la envías por email o imprimes para entregar
```

### Escenario 2: Cliente en Expo
```
1. Cliente visita tu stand en la expo
2. Muestra interés en varios muebles
3. Registras sus datos en el sistema
4. Marcas la expo específica donde está
5. Creas carrito con productos de interés
6. Generas cotización para enviar después
```

### Escenario 3: Seguimiento Post-Visita
```
1. Cliente visitó la sucursal días atrás
2. Solicita cotización de los productos que vio
3. Buscas su registro en el sistema
4. Actualizas o creas su carrito
5. Generas y envías la cotización actualizada
```

## Integración con Otras Secciones

### Con Catálogo de Productos
Los productos que agregas al carrito del cliente provienen del **Catálogo de Productos**. Asegúrate de que el catálogo esté actualizado con información precisa.

### Con Airtable
Toda la información de clientes y cotizaciones se sincroniza con tu **Base de Datos Airtable**, donde puedes ver historial completo y hacer análisis más profundos.

### Con Reportes y Analítica
Las cotizaciones generadas aparecen en tus **Reportes**, permitiéndote analizar:
- Cuántas cotizaciones se generan por sucursal
- Qué productos son más cotizados
- Tasa de conversión de cotizaciones a ventas

## Solución de Problemas Comunes

### "No puedo agregar un cliente"
- Verifica tu conexión a internet
- Confirma que todos los campos obligatorios estén llenos
- Intenta refrescar la página
- Contacta a Soporte Interzekt si persiste

### "El PDF no se genera"
- Verifica que el carrito tenga al menos un producto
- Confirma que los productos tengan precios asignados
- Intenta de nuevo después de unos segundos
- Revisa la consola del navegador por errores

### "No encuentro un cliente que registré"
- Usa la función de búsqueda en Airtable
- Verifica que hayas guardado correctamente el registro
- Confirma que estés buscando en la sucursal correcta
- Contacta a soporte si el cliente no aparece

### "La cotización tiene información incorrecta"
- Edita el carrito del cliente antes de regenerar
- Verifica los precios en el catálogo de productos
- Regenera el PDF después de hacer cambios
- Guarda una nueva versión con información correcta

## Consejos Profesionales

- Aprende los atajos de teclado para navegar más rápido
- Mantén plantillas de productos populares para agregar rápidamente

- Muestra la cotización al cliente antes de enviarla

### Seguimiento

- Registra en notas las fechas importantes de contacto con el cliente

## Preguntas Frecuentes

**¿Puedo editar un cliente después de crearlo?**
Sí, puedes editar la información del cliente desde Airtable o desde la sección correspondiente del dashboard.

**¿Las cotizaciones expiran?**
Depende de la política de Kusam. Generalmente, los precios pueden cambiar, por lo que se recomienda generar cotizaciones actualizadas si ha pasado mucho tiempo.

**¿Puedo generar múltiples cotizaciones para el mismo cliente?**
Sí, puedes generar tantas cotizaciones como necesites, cada una con diferentes productos o configuraciones.

**¿Dónde se guardan las cotizaciones generadas?**
Las cotizaciones se registran en Airtable y en los reportes del sistema. El PDF se descarga a tu dispositivo.

**¿Puedo personalizar el formato del PDF?**
El formato de la cotización es estándar de Kusam. Para personalizaciones especiales, contacta a Soporte Interzekt.
