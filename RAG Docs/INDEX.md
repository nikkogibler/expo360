## Cómo Usar Este Índice

### Para Configurar el Sistema RAG:
1. **SYSTEM_INSTRUCTIONS.md** → Carga como system prompt del LLM
2. **Documentos 01-07** → Genera embeddings para vector database (Pinecone)
3. **INDEX.md** (este archivo) → Referencia rápida, opcional incluir en RAG
4. **README.md** → Guía de implementación, NO incluir en RAG

### Para el Chatbot:
El asistente debe:
1. Recibir pregunta del usuario
2. Buscar en vector database los documentos relevantes
3. Usar SYSTEM_INSTRUCTIONS como contexto base
4. Responder usando información de documentos encontrados
5. Limitar respuesta a 300 caracteres
6. Siempre en español

### Jerarquía de Información:
```
SYSTEM_INSTRUCTIONS.md
    ↓
(Define cómo responder)
    ↓
01_vista_general_dashboard.md
    ↓
(Overview de todo el sistema)
    ↓
02-07_[funcionalidades].md
    ↓
(Detalles específicos por sección)
```
