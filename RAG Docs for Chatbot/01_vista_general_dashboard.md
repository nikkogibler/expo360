# Dashboard Kusam - Guía General

## ¿Qué es el Dashboard Kusam?

El Dashboard Kusam es tu centro de control administrativo para gestionar todos los aspectos del negocio de Kusam. Desde aquí puedes administrar clientes, productos, imágenes, reportes y mucho más, todo en un solo lugar.

## Acceso al Dashboard

### URL de Acceso
El dashboard se encuentra en: `kusam.vercel.app/admin`

### Inicio de Sesión
- Solo usuarios autorizados pueden acceder al dashboard
- Necesitas tu correo electrónico registrado como administrador
- Si no puedes acceder, contacta a Soporte Interzekt

## Navegación Principal

El dashboard está organizado en tarjetas visuales que representan cada sección principal:

### 📊 Analítica y Reportes
Visualiza métricas, estadísticas y análisis de tu negocio. Aquí encuentras gráficos de ventas, conversiones, rendimiento de productos y más.

**¿Cuándo usarlo?**
- Revisar métricas de rendimiento
- Analizar tendencias de ventas y/o los favoritos de los clientes
- Evaluar éxito de campañas
- Tomar decisiones basadas en datos

### 👥 Agregar Clientes + Cotización Automática
Aquí puedes agregar clientes a tu base de datos específicamente desde la sucursal o expo correspondiente. Además puedes generar su carrito y una cotización en PDF que le podrás enviar o imprimir.

**¿Cuándo usarlo?**
- Agregar nuevos clientes manualmente desde la tienda o expo correspondiente cuando ellos prefieran no hacerlo ellos mismos. 
- Generar carritos de compra para clientes
- Crear cotizaciones en PDF para enviar o imprimir

### 🛋️ Catálogo de Productos
Administra el catálogo completo de muebles y productos Kusam. Actualmente puedes agregar nuevos productos y nuevas variables. Próximamente podrás editar productos existentes, gestionar precios y características.

**¿Cuándo usarlo?**
- Agregar nuevos productos al catálogo
- Agregar nuevas variables como colores de tela o acabados de estructura
- Consultar el catálogo existente

### 🎨 Pro-Shot-Now

**🎨 ProShotNow™: Optimizador**
Herramienta de IA para mejorar la calidad de tus fotografías de productos. Optimiza automáticamente imágenes para que se vean profesionales.

**¿Cuándo usarlo?**
- Generar nuevas fotografías
- Mejorar calidad de fotos de productos existentes
- Estandarizar iluminación y colores
- Preparar imágenes para catálogo

**🖼️ ProShotNow™: Librería de Imágenes**
Tu repositorio central de todas las fotografías y recursos visuales. Organiza, busca y gestiona todas las imágenes de productos, sucursales y marketing.

**¿Cuándo usarlo?**
- Buscar imágenes específicas
- Organizar recursos visuales
- Descargar imágenes para campañas

**✨ ProShotNow™: Prompts**
Gestiona las instrucciones que guían a la IA en la optimización de imágenes. Aquí creas y editas los "prompts" que determinan cómo se procesan las fotos.

**¿Cuándo usarlo?**
- Experimentar con diferentes prompts
- Buscar prompts utilizados anteriormente
- Generar prompts nuevos

### 📋 Airtable
Acceso directo a tu base de datos empresarial Airtable. Aquí se almacena información detallada de clientes, productos, cotizaciones y gestión de ventas.

**¿Cuándo usarlo?**
- Consultar datos detallados de cada cliente
- Revisar información de productos y cotizaciones
- Acceder a información operativa y de ventas

### ⚙️ Configuraciones (Menú de Navegación)
Ajusta las configuraciones del sistema, permisos de usuarios, integraciones y preferencias generales del dashboard.

**¿Cuándo usarlo?**
- Ajustar preferencias del sistema
- Gestionar usuarios y permisos
- Configurar integraciones

### 🆘 Soporte Interzekt
Contacto directo con el equipo de soporte técnico de Interzekt.com vía WhatsApp para resolver dudas, reportar problemas o solicitar nuevas funcionalidades.

**¿Cuándo usarlo?**
- Reportar errores técnicos
- Solicitar ayuda con funcionalidades
- Proponer mejoras al sistema
- Resolver problemas urgentes
- Obtener asistencia técnica especializada

## Navegación entre Secciones

### Desde el Dashboard Principal
Haz clic en cualquier tarjeta para acceder a esa sección específica.

### Menú de Navegación
En la parte superior encontrarás el menú principal que te permite:
- Regresar al dashboard principal
- Acceder rápidamente a cualquier sección
- Ver tu sesión activa
- Cerrar sesión

### Ruta de Navegación (Breadcrumbs)
En cada página verás la ruta actual, ejemplo:
`Dashboard > Catálogo > Editar Producto`

Esto te ayuda a saber dónde estás y regresar fácilmente.

## Solución de Problemas Comunes

### "No puedo acceder al dashboard"
- Verifica que estés usando el correo autorizado
- Limpia caché y cookies del navegador
- Contacta a Soporte Interzekt

### "La página no carga"
- Verifica tu conexión a internet
- Recarga la página (F5 o Cmd+R)
- Prueba en otro navegador

### "No encuentro una función"
- Consulta esta documentación
- Pregunta al Asistente Kusam (chatbot)
- Contacta a Soporte Interzekt
