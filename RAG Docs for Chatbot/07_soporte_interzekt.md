# Soporte Interzekt - Asistencia Técnica

## Descripción General

Interzekt es el equipo técnico detrás del Dashboard Kusam. Está disponible para ayudarte con problemas técnicos, reportar errores, solicitar nuevas funcionalidades y resolver cualquier duda especializada sobre el sistema.

## Acceso a Soporte Interzekt

### Desde el Dashboard Principal
1. Busca la tarjeta "🆘 Soporte Interzekt"
2. Haz clic para acceder
3. Se abrirá el contacto directo vía WhatsApp

### Contacto Directo
- **WhatsApp:** Número proporcionado en la tarjeta de soporte
- **Email:** soporte@interzekt.com (o email proporcionado)

## Cómo Contactar Efectivamente

### Por WhatsApp (Recomendado para Urgencias)

**Ventajas:**
- Respuesta rápida
- Conversación fluida
- Fácil enviar capturas de pantalla
- Seguimiento en tiempo real

**Cómo hacerlo:**
1. Accede desde la tarjeta "Soporte Interzekt" en el dashboard
2. Se abre WhatsApp con el número de Interzekt
3. Saluda y explica tu problema claramente
4. Envía capturas de pantalla si es necesario

**Información a Incluir:**
```
Hola, equipo Interzekt:

[Tu nombre] - Dashboard Kusam

Problema: [Descripción breve]

- ¿Qué esperabas que pasara?
- ¿Qué pasó en realidad?

[Adjunta captura de pantalla si aplica]

¡Gracias!
```

- Seguimiento estructurado

- [Capturas de pantalla]

## Información Útil para Reportar Problemas

### Siempre Incluye:

1. **¿Qué estabas intentando hacer?**
   - Ejemplo: "Intentaba subir una imagen al Optimizador"

2. **¿Qué esperabas que pasara?**
   - Ejemplo: "Esperaba que se subiera y procesara la foto"

3. **¿Qué pasó en realidad?**
   - Ejemplo: "Se quedó cargando y luego mostró error"

4. **¿Cuándo empezó el problema?**
   - Ejemplo: "Desde hoy en la mañana" o "Solo esta vez"

5. **¿Has intentado algo para resolverlo?**
   - Ejemplo: "Intenté refrescar la página pero sigue igual"

### Capturas de Pantalla

**Cuándo enviarlas:**
- Mensajes de error
- Comportamiento visual extraño
- Confusión sobre dónde está algo
- Resultados inesperados

**Cómo tomarlas:**
- **Mac:** Cmd + Shift + 4 (seleccionar área)
- **Windows:** Win + Shift + S
- **Chrome:** Extensiones de captura disponibles

**Qué capturar:**
- El error completo (si hay mensaje)
- La pantalla donde ocurre el problema
- Menús o botones relevantes

## Tipos de Solicitudes Comunes

### Solicitud 1: Reportar un Error

**Plantilla:**
```
Problema: No puedo generar cotizaciones en PDF

Pasos:
1. Accedo a "Agregar Clientes +"
2. Creo carrito con productos
3. Hago clic en "Generar Cotización"
4. Se queda cargando y no genera nada

Esperado: Que genere el PDF para descargar
Real: Solo carga indefinidamente

Navegador: Chrome versión 120
Ocurre: Desde ayer
```

### Solicitud 2: Pedir Nueva Funcionalidad

**Plantilla:**
```
Solicitud: Poder duplicar productos en el Catálogo

Razón: Cuando agrego productos similares, tengo que 
llenar todo desde cero. Si pudiera duplicar uno existente 
y solo cambiar lo diferente, ahorraría mucho tiempo.

Beneficio: Más eficiencia al agregar productos nuevos, 
especialmente variantes de productos existentes.

Prioridad: Media (sería muy útil pero no bloquea trabajo)
```

### Solicitud 3: Obtener Más Créditos

**Plantilla:**
```
Solicitud: Adquirir más créditos para Pro-Shot-Now™

Créditos actuales: 15 restantes
Necesidad: Aproximadamente 200 créditos mensuales
Uso principal: Generar fotos de nuevos productos

Pregunta: ¿Qué paquetes tienen disponibles y cuál 
me recomendarían según mi uso?
```

### Solicitud 4: Agregar Nuevo Usuario

**Plantilla:**
```
Solicitud: Agregar nuevo usuario administrador

Nombre: [Nombre completo]
Email: [email@dominio.com]
Rol: Administrador con acceso a [especificar secciones]

Permisos necesarios:
- Ver y generar reportes
- Agregar clientes y cotizaciones
- NO necesita acceso a configuraciones

Razón: Nuevo miembro del equipo de ventas
```

## Tiempos de Respuesta Esperados

### WhatsApp
- **Horario laboral:** 30 minutos - 2 horas
- **Fuera de horario:** Siguiente día laborable
- **Urgencias críticas:** Indicar en mensaje

### Email
- **Primera respuesta:** 24 horas hábiles
- **Resolución:** Depende de complejidad
  - Simple: 1-2 días
  - Media: 3-5 días
  - Compleja: 1-2 semanas

### Solicitudes de Funcionalidades
- **Evaluación:** 1 semana
- **Implementación:** Variable (días a semanas)
- **Te notifican:** Cuando esté lista la función

## Preguntas Frecuentes sobre Soporte

**¿El soporte tiene costo adicional?**
El soporte básico está incluido. Funcionalidades personalizadas complejas pueden tener costo adicional.

**¿Hay horario de atención?**
Generalmente horario laboral de lunes a viernes. WhatsApp puede revisarse fuera de horario para urgencias.

**¿Puedo llamar por teléfono?**
WhatsApp es el canal preferido. Para casos muy urgentes, pregunta si hay línea telefónica disponible.

**¿Qué tan rápido responden?**
Depende del canal y urgencia. WhatsApp es más rápido que email.

**¿Puedo solicitar una reunión/llamada?**
Sí, para capacitación o problemas complejos, puedes solicitar videollamada o reunión.

**¿Interzekt da soporte en español?**
Sí, todo el soporte es en español.

## Mejores Prácticas al Contactar Soporte

### ✅ Hacer:

- Ser claro y específico en la descripción
- Incluir pasos para reproducir el problema
- Adjuntar capturas de pantalla relevantes
- Indicar nivel de urgencia honestamente
- Ser paciente con tiempos de respuesta
- Agradecer la ayuda recibida

### ❌ Evitar:

- Mensajes vagos como "no funciona"
- Reportar múltiples problemas en un solo mensaje
- Ser impaciente o grosero
- Exagerar urgencia de problemas no críticos
- Esperar respuesta inmediata fuera de horario laboral
- Contactar por múltiples canales simultáneamente
