# Catálogo de Productos - Dashboard Kusam

## Descripción General

La sección de Catálogo de Productos te permite explorar y gestionar el catálogo completo de muebles Kusam. Actualmente puedes **agregar nuevos productos** y **agregar nuevas variables** (como colores de tela o acabados de estructura). La función de editar productos existentes estará disponible próximamente.

## Acceso al Catálogo

### Desde el Dashboard Principal
1. Busca la tarjeta "🛋️ Catálogo de Productos"
2. Haz clic para acceder

### URL Directa
`kusam.vercel.app/admin/catalogo` (o ruta configurada)

## Agregar Nuevo Producto

### ¿Cuándo Agregar un Producto?

- Kusam lanza una nueva colección
- Llega un modelo nuevo al inventario
- Se crea un producto especial o edición limitada
- Necesitas documentar un producto que no está en el sistema

### Información que Necesitas Preparar

#### Información Básica (Obligatoria)
1. **Nombre del Producto**
   - Nombre descriptivo y claro
   - Ejemplo: "Sofá Modular Pearl 3 Plazas"
   - Incluye colección y características principales

2. **SKU (Stock Keeping Unit)**
   - Código único del producto
   - Ejemplo: "KUS-SOF-PRL-003"
   - Debe ser único, no duplicar
   - Sigue nomenclatura de Kusam

3. **Categoría**
   - Sofás y Salas
   - Sillones
   - Mesas
   - Sillas y Comedores
   - Exterior/Jardín
   - Accesorios
   - Otros

4. **Precio Base**
   - Precio regular del producto
   - En pesos mexicanos (MXN)
   - Sin incluir variables (se agregan después)

#### Información Detallada (Recomendada)

5. **Descripción**
   - Texto que describe el producto
   - Materiales principales
   - Características distintivas
   - Beneficios clave

6. **Especificaciones Técnicas**
   - Dimensiones: Alto x Ancho x Profundidad
   - Peso (si disponible)
   - Materiales de fabricación
   - Capacidad (para sofás/sillas)

7. **Imágenes**
   - Al menos 1 imagen principal
   - Preferentemente 4-6 imágenes desde diferentes ángulos
   - Formato JPG o PNG
   - Resolución adecuada para web

### Pasos para Agregar Producto

#### Paso 1: Iniciar Creación
1. En el Catálogo, haz clic en "Agregar Nuevo Producto" o botón "+"
2. Se abrirá el formulario de creación

#### Paso 2: Completar Información Básica

**Ejemplo de llenado:**
```
Nombre: Sofá Modular Pearl 3 Plazas
SKU: KUS-SOF-PRL-003
Categoría: Sofás y Salas
Subcategoría: Modulares
```

#### Paso 3: Agregar Precio

```
Precio Base: $45,999.00 MXN
(Nota: Este es el precio sin personalización. 
Las variables pueden tener costos adicionales)
```

#### Paso 4: Escribir Descripción

**Ejemplo:**
```
El Sofá Modular Pearl es una pieza contemporánea perfecta 
para espacios modernos. Su estructura de aluminio resistente 
y cojines de alta densidad garantizan durabilidad y confort. 
Diseño modular que permite adaptarse a diferentes espacios.

Características:
- Estructura de aluminio powder-coated
- Cojines de foam de alta densidad
- Tela resistente a intemperie (para exterior)
- Diseño modular reconfigurable

Dimensiones:
- Largo: 210 cm
- Profundidad: 90 cm  
- Altura: 75 cm
```

#### Paso 5: Subir Imágenes

1. Haz clic en "Agregar Imagen" o zona de carga
2. Selecciona imagen(es) de tu dispositivo
3. La primera imagen será la principal
4. Agrega más imágenes mostrando diferentes ángulos

**Tip:** Usa imágenes generadas con Pro-Shot-Now™ para calidad consistente.

#### Paso 6: Definir Especificaciones

Completa campos técnicos:
- Alto: 75 cm
- Ancho: 210 cm
- Profundidad: 90 cm
- Peso: 45 kg (aproximado)
- Material: Aluminio + Tela

#### Paso 7: Guardar Producto

1. Revisa que toda la información sea correcta
2. Haz clic en "Guardar" o "Crear Producto"
3. El producto se agregará al catálogo
4. Verás confirmación de creación exitosa

## Agregar Nuevas Variables

### ¿Qué son las Variables?

Las variables son las **opciones de personalización** que los clientes pueden elegir para un producto. En Kusam, las principales variables son:

- **Colores de Tela:** Arena, Ecru, Anthracite, Dune, etc.
- **Acabados de Estructura:** Negro, Blanco, Grafito, Natural, etc.

### ¿Cuándo Agregar una Variable?

- Kusam incorpora un nuevo color de tela a su colección
- Llega un nuevo acabado de estructura
- Se crea una opción especial o de temporada
- Necesitas documentar una variable que no está en el sistema

### Tipos de Variables

#### Variables de Tela
Colores y materiales de tapicería/cojines disponibles.

**Ejemplos:**
- Arena
- Ecru  
- Pearl
- Anthracite
- Dune
- Ocean Blue
- River
- Jade

#### Variables de Estructura
Acabados y colores de marcos/estructuras.

**Ejemplos:**
- Negro Mate
- Blanco
- Grafito
- Natural (madera)
- Bronce
- Aluminio Cepillado

### Pasos para Agregar Variable

#### Paso 1: Iniciar Creación
1. En el Catálogo, haz clic en "Agregar Nueva Variable"
2. Selecciona tipo: Tela o Estructura

#### Paso 2: Completar Información de la Variable

**Para Variable de Tela:**
```
Nombre: Ocean Blue
Tipo: Tela
Descripción: Tela de alto rendimiento color azul océano, 
             resistente a intemperie y rayos UV
Código: TELA-OCN-BLU
Costo adicional: +$2,500 MXN (si aplica)
```

**Para Variable de Estructura:**
```
Nombre: Negro Mate
Tipo: Estructura/Acabado
Descripción: Acabado powder-coated negro mate para 
             estructuras de aluminio
Código: EST-NEG-MAT
Costo adicional: $0 (precio base)
```

#### Paso 3: Subir Imagen de Muestra (Opcional)

- Sube una foto que muestre la tela o acabado
- Ayuda a visualizar el color/textura
- Puede ser una muestra o producto con esa variable

#### Paso 4: Asignar a Productos

Selecciona a qué productos aplica esta variable:
- Todos los sofás de exterior
- Colección Pearl completa
- Productos específicos

#### Paso 5: Guardar Variable

1. Revisa información
2. Haz clic en "Guardar Variable"
3. La variable estará disponible para usar en productos

## Mejores Prácticas

### Para Agregar Productos

**✅ Hacer:**
- Usar nombres descriptivos y consistentes
- Verificar que el SKU sea único
- Incluir descripciones completas y precisas
- Subir imágenes de alta calidad
- Definir especificaciones técnicas exactas
- Revisar precios antes de guardar

**❌ Evitar:**
- Nombres genéricos como "Sofá 1", "Mueble"
- SKUs duplicados o confusos
- Descripciones vagas o incompletas
- Imágenes de baja calidad o pixeladas
- Dejar campos importantes vacíos
- Precios incorrectos o desactualizados

### Para Agregar Variables

**✅ Hacer:**
- Usar nombres de colores consistentes con nomenclatura Kusam
- Incluir descripción técnica del material
- Definir si tiene costo adicional
- Subir imagen de muestra representativa
- Asignar correctamente a productos aplicables

**❌ Evitar:**
- Nombres ambiguos ("Azul 1", "Gris")
- Variables duplicadas con nombres diferentes
- Dejar sin definir el costo adicional
- Asignar variables a productos incompatibles

## Flujo de Trabajo Típico

### Escenario: Lanzamiento de Nueva Colección

**Paso 1: Preparación**
- Recibe información de productos de la nueva colección
- Reúne fotos, descripciones, precios, especificaciones

**Paso 2: Generación de Imágenes**
- Usa Pro-Shot-Now™ para generar fotos profesionales
- Crea variantes con diferentes telas y estructuras
- Guarda en Librería organizadas por producto

**Paso 3: Agregar Variables Nuevas (si aplica)**
- Si la colección incluye nuevos colores/acabados
- Agrega primero las variables al sistema
- Define nombres, códigos y precios adicionales

**Paso 4: Agregar Productos**
- Crea ficha para cada producto de la colección
- Completa toda la información requerida
- Asigna las variables disponibles a cada producto
- Sube las imágenes desde la Librería

**Paso 5: Revisión**
- Verifica que todos los productos estén correctos
- Confirma precios y descripciones
- Prueba búsquedas y filtros

**Paso 6: Activación**
- Productos están listos para:
  - Ser incluidos en cotizaciones
  - Mostrarse en el sitio web (si integrado)
  - Usarse en presentaciones de ventas

## Solución de Problemas Comunes

### "No puedo agregar un producto"
- Verifica que todos los campos obligatorios estén llenos
- Confirma que el SKU sea único (no duplicado)
- Revisa tu conexión a internet
- Intenta refrescar la página
- Contacta a Soporte Interzekt si persiste

### "La imagen no se sube"
- Verifica el formato (JPG, PNG, WEBP)
- Confirma que el tamaño no exceda el límite (típicamente 5MB)
- Intenta con una imagen diferente
- Comprime la imagen si es muy pesada

### "No encuentro un producto que agregué"
- Usa la barra de búsqueda por nombre o SKU
- Verifica los filtros activos (pueden estar ocultándolo)
- Revisa en la categoría correcta
- Confirma que el producto se haya guardado exitosamente

### "Necesito editar un producto pero no puedo"
- La función de edición estará disponible próximamente
- Mientras tanto, contacta a Soporte Interzekt para ediciones urgentes
- Para cambios menores, puede ser más rápido esperar la actualización

### "¿Cómo elimino un producto?"
- La eliminación debe hacerse con precaución
- Contacta a Soporte Interzekt para solicitar eliminación
- Considera desactivar en lugar de eliminar permanentemente

## Preguntas Frecuentes

**¿Cuándo estará disponible la función de editar productos?**
Próximamente. Se está trabajando en esta funcionalidad y se notificará cuando esté lista.

**¿Puedo duplicar un producto existente para crear uno similar?**
Esta función también estará disponible próximamente. Mientras tanto, deberás crear el producto desde cero.

**¿Las variables aplican a todos los productos?**
No, cada variable se asigna solo a los productos compatibles. Por ejemplo, telas de exterior solo para muebles de exterior.

**¿Puedo agregar variables personalizadas?**
Sí, puedes crear cualquier variable que Kusam ofrezca. Si necesitas un tipo especial de variable, contacta a Soporte.

**¿Los productos agregados aparecen automáticamente en el sitio web?**
Depende de la configuración. Algunos productos pueden requerir aprobación o sincronización manual.

**¿Hay límite de productos que puedo agregar?**
No hay límite técnico. Puedes agregar tantos productos como necesites.
